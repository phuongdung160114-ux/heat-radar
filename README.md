# HEAT RADAR

A 股热度与事件追踪工具。在本地采集人气榜、资讯、公告和公司资料，比较关注度变化，保存题材与股票的观察记录。

程序通过浏览器使用，数据保存在本机。首页按热度变化和研究优先级排列候选，详情页展示关注证据、事件变化和业务关系。

## Windows 安装

1. 在仓库页面点击 **Code → Download ZIP**，下载后完整解压。
2. 双击 `一键安装_Windows.cmd`，等待依赖安装完成。
3. 安装完成后会打开网页。以后双击 `启动热度雷达_Windows.cmd`，也可以使用桌面的 `Ashare Heat Radar` 快捷方式。

安装需要联网，支持 Windows x64。安装程序会寻找 Python 3.11–3.13；没有合适版本时，会从 Python 官网下载并安装独立的 Python 环境。

网页默认地址是 `http://127.0.0.1:8787`。端口被其他程序占用时，会自动尝试后续端口，以运行窗口显示的地址为准。

## 手动运行

使用 Python 3.11–3.13。在项目目录打开 PowerShell：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

如果安装的是 Python 3.11 或 3.12，将第一行的版本号改为对应版本。

常用启动参数：

```powershell
# 指定端口
.\.venv\Scripts\python.exe run.py --port 8899

# 使用已有数据，不自动联网采集
.\.venv\Scripts\python.exe run.py --no-auto

# 指定数据目录
.\.venv\Scripts\python.exe run.py --data-dir "D:\HeatRadarData"

# 不自动打开浏览器
.\.venv\Scripts\python.exe run.py --no-browser
```

手动运行时，在命令窗口按 `Ctrl+C` 停止程序。关闭浏览器页面不会停止后台采集。

## 第一次使用

打开“数据来源与接入”，检查需要使用的来源是否启用，然后点击“测试已启用来源”。也可以在首页点击“采集并筛选”。

各来源的状态会分别显示。某个来源失败时，先查看该来源的错误记录；其他来源仍可继续采集。

首次使用先完成一轮采集，再查看候选和详情。点击“回填可得历史”补充来源提供的历史记录；盘中观察、热度变化和后续表现会随日常采集持续积累。

## 页面功能

| 页面 | 用途 |
|---|---|
| 板块与个股 | 查看候选、切换排序目标、搜索股票、打开详情、保留观察对象和导出结果 |
| 题材发现与传播 | 查看新词、题材成员和业务关系图 |
| 量化研究实验室 | 更新后续标签，运行逻辑回归、岭回归或 LambdaMART 实验 |
| 盘前海外映射 | 查看已接入的海外信息及其与国内对象的关系 |
| 数据来源与接入 | 开关来源、查看采集状态、填写凭据、导入 JSON 或 JSONL |
| 历史与检验 | 查看保存的筛选记录、回填历史、备份数据库、观察名单后续表现 |
| 参数与主题 | 修改筛选条件、关注清单、主题词和业务关系 |

“更新筛选”使用库中已有数据重新计算；“采集并筛选”会先联网获取数据，再计算。

运行研究实验前，先积累观测数据并更新后续标签。默认排序采用规则分位数；完成训练并启用模型后，切换为对应模型排序。

## 数据来源

默认接入东方财富、雪球、财联社、互动易等公开数据。大部分接口通过 AKShare 调用。

东方财富人气榜和个股概况使用项目内的适配代码。旧行情入口断连时，会尝试东方财富备用入口，并保留实际来源。人气排名来自原人气榜，股票名称补充失败不会丢弃已取得的排名。

Tushare、X、Reddit 和外部数据服务需要各自的凭据或访问权限，默认不开启。RSS 和本地文件来源需要自行配置。

## 数据放在哪里

| 安装方式 | 默认位置 |
|---|---|
| Windows 一键安装，项目内没有 `.venv` | `%LOCALAPPDATA%\AshareHeatRadar\data` |
| 手动安装，或使用项目内已有 `.venv` | 项目目录下的 `data` |
| 指定 `--data-dir` | 指定的目录 |

数据库在数据目录的 `live/radar.sqlite`，设置在 `settings.json`，运行日志在 `logs/app.log`。Windows 安装日志位于 `%LOCALAPPDATA%\AshareHeatRadar\logs`；使用项目内环境时位于 `data/logs`。

在“历史与检验”中点击备份按钮即可导出数据库。迁移到其他电脑时，另外复制 `settings.json`，一并带走设置和来源凭据。

## 常见问题

- **双击后无法启动**：运行 `修复依赖_Windows.cmd`；仍然失败时保留窗口中的错误内容，并查看安装或运行日志。
- **网页没有自动打开**：在浏览器输入运行窗口中的本地地址。
- **某个数据来源失败**：查看“数据来源与接入”中的具体错误。需要授权的来源先检查凭据；公开来源断连时可等待下次采集。
- **没有模型或研究结果**：先积累观测数据并更新后续标签，再运行实验。
- **日期超出范围**：内置交易日历覆盖 2025-01-01 至 2026-12-31。使用其他年份时，按交易所公布的安排更新 `config/calendar.json` 和 `tools/build_calendar.py`。

## macOS 与 Linux

仓库包含对应的安装和启动脚本，需要 Python 3.11–3.13。Linux 需要 Python 的 venv 模块，macOS 上的 LightGBM 需要 OpenMP。

## 目录

```text
config/        默认设置、交易日历、主题词和业务关系
installers/    安装与启动脚本
radar/         采集、存储、分析和网页接口
static/        网页文件
tools/         导入、维护和研究命令
run.py         启动入口
```

提交问题时附上系统、Python 版本、涉及的来源、操作步骤和错误内容。
